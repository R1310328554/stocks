# stocks

## 一、整体架构设计

系统采用**七层架构**，从数据采集到最终决策输出形成闭环：

```
┌─────────────────────────────────────────────────────────────┐
│                        应用层                              │
│  Web端 / App端 / 微信小程序 / 告警推送                      │
├─────────────────────────────────────────────────────────────┤
│                      决策引擎层                            │
│  选股策略引擎 / 择时信号引擎 / 诊股引擎 / 回测引擎          │
├─────────────────────────────────────────────────────────────┤
│                      分析计算层                            │
│  技术指标计算 / 基本面评分 / 资金流分析 / 情绪感知          │
├─────────────────────────────────────────────────────────────┤
│                      数据服务层                            │
│  行情数据服务 / 财务数据服务 / 新闻公告服务 / 研报服务      │
├─────────────────────────────────────────────────────────────┤
│                      数据采集层                            │
│  定时采集 / 实时推送 / 消息队列 / 数据清洗与归一化          │
├─────────────────────────────────────────────────────────────┤
│                      数据存储层                            │
│  时序数据库(行情) / 关系数据库(元数据) / 向量数据库(新闻)   │
├─────────────────────────────────────────────────────────────┤
│                      数据源层                              │
│  Tushare / akshare / 同花顺 / 东方财富 / 巨潮资讯 /  Wind  │
└─────────────────────────────────────────────────────────────┘
```

参考华泰AI涨乐的**多专家Agent协同架构**，可由主Agent统筹调度，联动宏观分析、产业链研究、财报解读、技术回测等多个专家智能体协同作业。


## 二、数据源层——详细清单

### 2.1 行情数据

| 数据源 | 数据类型 | 接入方式 | 适用场景 | 备注 |
|--------|---------|---------|---------|------|
| **Tushare Pro** | Level-1行情、K线、指数、板块 | HTTP SDK | 量化回测、个人研究者 | 需积分+API Key |
| **akshare** | 同花顺/东方财富全量数据 | Python库 | 快速验证、探索阶段 | 覆盖面最广，免费 |
| **mootdx** | 通达信实时行情 | TCP直连 | 实时行情、技术流开发者 | 免费，需国内服务器 |
| **同花顺热点** | 题材归因信号 | HTTP零鉴权 | 事件驱动策略 | 信息密度极高 |
| **Wind** | 机构级全数据 | 企业级SDK | 持牌机构、合规要求 | 行业基准，费用高 |
| **TickDB** | 程序化实时行情API | WebSocket | 接系统/Agent/监控面板 | 为开发者设计 |

### 2.2 财务与基本面数据

| 数据内容 | 推荐来源 | 说明 |
|---------|---------|------|
| 三大报表（利润表/资产负债表/现金流量表） | Tushare Pro / akshare-同花顺 | 季度/年度数据 |
| 核心财务比率（ROE/ROA/毛利率/净利率） | Tushare Pro | 需自行计算或使用接口 |
| 估值指标（PE/PB/PS/股息率） | Tushare Pro / 腾讯财经 | 每日更新 |
| F10资料（公司概况/高管/股东） | akshare-巨潮 | 公告披露数据 |

### 2.3 新闻、公告、政策数据

| 数据内容 | 推荐来源 | 接入方式 | 说明 |
|---------|---------|---------|------|
| **上市公司公告** | 巨潮资讯CNINFO | HTTP API / Apify Actor | 公告标题、时间、代码、PDF链接 |
| **财经新闻** | 同花顺/东方财富 | a-stock-data封装 | 实时新闻流 |
| **政策动态** | 政府网站 / 同花顺 | 需自行爬取或接入 | 无标准化API |
| **研报** | 东财reportapi / 同花顺 / iwencai | HTTP API | 研报列表、PDF下载、机构一致预期EPS |
| **舆情互动** | 互动易 / 热榜 / 人气榜 | a-stock-data封装 | 投资者问答、热度 |
| **财经文本** | RESSET财经文本平台 | 数据API | 近500万篇年报/公告文本 |

**关键开源工具**：`a-stock-data`——零依赖直连13大数据源28个端点，覆盖行情、研报、资金、新闻、公告全场景。

### 3.1 核心功能全景图

### 3.2 智能选股模块（核心）

**（1）多因子选股**

参考国泰海通智能优选的**60项因子综合打分**，构建多因子评分体系：

| 因子大类 | 具体因子 | 数据来源 |
|---------|---------|---------|
| **价值因子** | PE、PB、PS、PCF、股息率 | Tushare Pro |
| **成长因子** | 营收增长率、净利润增长率、EPS增长率 | 财务数据 |
| **质量因子** | ROE、ROA、毛利率、净利率、资产负债率 | 财务数据 |
| **动量因子** | 过去N日收益率、RSI、MACD | 行情数据 |
| **资金因子** | 主力净流入、北向持股变化、融资余额变化 | 资金流数据 |
| **情绪因子** | 换手率、成交量变化、波动率 | 行情数据 |

**（2）热点选股**

参考华泰AI涨乐的**热点、连板、主题、资金四大维度选股工具**：
- 题材归因：同花顺热点接口（零鉴权）
- 涨停板监测：涨停池、连板、炸板率
- 龙虎榜数据：机构席位追踪

**（3）形态选股**

参考国泰海通**28种经典技术形态**捕捉K线趋势：
- 头肩顶/底、双顶/底、三角形突破、旗形、楔形
- 需实现形态识别算法库

**（4）自然语言选股**

参考蜻蜓点金的智能条件选股——支持用户通过自然语言描述市盈率、净利润增长率、行业属性、技术形态等条件。

### 3.3 择时信号模块

| 信号类型 | 具体指标/方法 | 说明 |
|---------|-------------|------|
| **技术信号** | 均线交叉、MACD金叉死叉、布林带突破、RSI超买超卖 | 经典技术分析 |
| **资金信号** | 主力净流入/流出、大单动向、北向资金 | 资金面择时 |
| **情绪信号** | 恐慌贪婪指数、融资融券余额变化、换手率分位 | 市场情绪 |
| **事件信号** | 业绩预告、重大公告、政策发布 | 事件驱动 |

### 3.4 主力情绪感知器模块

**（1）资金流三源聚合监测**

参考开源项目`skill-capital-flow-crowding-monitor`的设计：

| 数据源 | 监测指标 | 信号含义 |
|--------|---------|---------|
| **融资融券** | 融资余额窗口变化 | 杠杆资金情绪（净流入=看多） |
| **北向持股** | 持股比例/持股数窗口变化 | 外资/聪明钱动向 |
| **大宗交易** | 成交额规模+折溢价+营业部 | 机构接盘/出货判断 |

**核心输出**：
- **共识信号**：三源方向一致 → 资金合力
- **背离信号**：方向打架 → 分歧，信号弱化
- **拥挤度分位**：当前资金强度在历史N天的分位，>90%为高拥挤预警

**（2）逐笔交易分析**

参考大智慧ACE（Active Capital Estimate）模型——基于逐笔交易数据对即时成交单分类汇总，根据主动性买卖单的笔数差和大单资金监控市场活跃交易者的情绪变化。

**（3）主力密码**

参考蜻蜓点金的“主力密码”工具，追踪主力资金动向。

### 3.5 AI盯盘模块

参考华泰AI涨乐的AI盯盘功能——实时监测市场信号并秒级推送股价异动：

| 监控类型 | 监控内容 | 推送方式 |
|---------|---------|---------|
| **股价异动** | 快速拉升/跳水、突破关键价位 | 秒级推送 |
| **成交量异动** | 放量/缩量异常 | 实时推送 |
| **资金异动** | 大单净流入/流出突增 | 实时推送 |
| **公告事件** | 持仓/自选股相关公告发布 | 即时推送 |
| **政策事件** | 行业相关政策发布 | 即时推送 |

### 3.6 智能诊股模块

参考蜻蜓点金的高级诊股功能，从多维度诊断：

| 诊断维度 | 分析内容 | 输出形式 |
|---------|---------|---------|
| **基本面** | 财务健康度、估值水平、成长性 | 评分+文字解读 |
| **技术面** | 趋势判断、支撑压力、买卖信号 | 图表+信号 |
| **资金面** | 主力动向、北向资金、融资融券 | 资金流向图 |
| **风险提示** | 财务风险、质押风险、解禁风险 | 风险清单 |

### 6.3 多因子选股模型

参考国泰海通**60项因子综合打分**，构建加权评分模型：

```
综合得分 = Σ(因子得分 × 因子权重)
```

因子权重可通过**历史回测**或**机器学习**（如XGBoost）优化。

## 八、开发优先级建议

作为十几年经验的开发者，建议按以下优先级推进：

**Phase 1（MVP，2-4周）** ：
1. 搭建数据采集层，接入Tushare Pro获取日K线和财务数据
2. 实现5-10个核心技术指标（MA、MACD、RSI、布林带等）
3. 实现简单的多因子选股（5-8个因子）
4. 搭建Web端展示选股结果

**Phase 2（4-8周）** ：
5. 接入实时行情（WebSocket）
6. 实现资金流三源聚合监测（融资融券+北向+大宗）
7. 实现AI盯盘和异动推送
8. 接入新闻公告数据

**Phase 3（8-12周）** ：
9. 实现智能诊股模块
10. 实现策略回测引擎
11. 接入自然语言选股（LLM）
12. 移动端App开发

**Phase 4（持续迭代）** ：
13. 策略优化与因子挖掘
14. 多专家Agent协同架构
15. 社区与分享功能
